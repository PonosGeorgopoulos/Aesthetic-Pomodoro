# Aesthetic Pomodoro Pro

A polished, immersive Pomodoro web application focused on productivity, calm visuals, and an enjoyable study/work flow.

## Description

Aesthetic Pomodoro Pro combines a configurable Pomodoro timer with a planning experience in a single-page interface. It includes focus/break modes, subject tracking, interactive charts, weather context, calendar workflows, and background audio to support deep work sessions.

## Summary

- **Purpose:** Help users stay focused and organized through timed work sessions.
- **Style:** Glassmorphism and neumorphic UI with nature-themed visuals.
- **Core features:** Timer modes, subject analytics, planner/calendar overlays, and progressive web app behavior.
- **Tech stack:** HTML, CSS, JavaScript, Service Worker, Web App Manifest.

## Project Structure

- `/index.html` — main application markup and UI layout
- `/style.css` — global styling, visual system, and component styles
- `/script.js` — application logic and feature behavior
- `/sw.js` — service worker caching strategy
- `/manifest.json` — PWA metadata and install settings
- `/images/` — static visual assets (backgrounds and favicon)

## Notes

This repository is intentionally lightweight and framework-free to keep deployment simple and fast.
